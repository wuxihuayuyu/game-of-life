# Game of Life · 生命游戏

John Conway 在 1970 年提出的元胞自动机,用一个单文件的网页实现。无需安装依赖,无需构建。

## 运行

直接用浏览器打开 `index.html` 即可。

## 规则

每个细胞只看周围 8 个邻居:

- 活细胞:邻居为 2 或 3 个则存活,否则死亡
- 死细胞:邻居恰好为 3 个则复活

网格是环形的,从一侧走出会从另一侧回来。

## 操作

| 操作 | 说明 |
| --- | --- |
| 鼠标左键 | 绘制活细胞,按住拖动可连续绘制 |
| 鼠标右键 / Shift + 左键 | 擦除 |
| 空格 | 开始 / 暂停 |
| S | 单步 |
| R | 随机初始化 |
| C | 清空 |
| 速度滑块 | 调整每秒演化的代数 |

## 可以尝试的图案

- **滑翔机**:页面打开时已经预置,会沿对角线移动
- **闪烁器(Blinker)**:三个连成一排的细胞,在横竖之间交替
- **方块(Block)**:2×2 的静止图案

## 技术细节

- 纯 HTML / CSS / JavaScript,使用 `<canvas>` 绘制
- 网格 80 × 50,每个细胞 10 像素
- 使用 `Uint8Array` 存储网格,并用双缓冲避免每代分配内存
